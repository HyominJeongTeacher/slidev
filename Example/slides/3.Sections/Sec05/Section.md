# 활동 4. 제공 코드로 진동수 피팅

- 이 연수는 코딩 강의가 아니라, 제공된 Colab 코드를 실행하고 결과를 해석하는 과정이다.
- 사인파 피팅 모델

$$
y = A\sin(2\pi ft + \phi) + C
$$

- 참가자는 코드 실행 후 다음을 확인한다.
  - 진폭(`A`): 파형의 크기
  - 진동수(`f`): 함수발생기 설정값과 비교
  - 오프셋(`C`): 평균값 또는 DC 성분

---

# 제공 Colab의 실행 순서(MBL활용)

1. 예제3를 활용해 CSV 또는 조별 측정 CSV를 업로드한다.
2. 시간 영역 파형과 확대 구간을 확인한다.
3. 제공된 피팅 셀을 실행하고 추정 진동수를 확인한다.
4. 설정값과 비교해 오차 원인을 토의한다.

> 파일 열 이름 오류, 피팅 실패, 샘플링레이트 누락 시에는 배포된 예제 CSV로 전환한다.

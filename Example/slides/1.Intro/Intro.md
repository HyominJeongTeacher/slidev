# 연수 기본 기기 조합과 대체 조합

<div class="grid grid-cols-2 gap-8 mt-8 text-left">
  <div class="p-5 border rounded-xl">
    <h3>연수 기본 기기 조합</h3>
    <p>함수발생기 + 스피커</p>
    <p>→ MBL 소리 센서</p>
    <p>→ 음압 데이터</p>
    <p>→ 컴퓨터 관찰 및 제공 코드 분석</p>
  </div>
  <div class="p-5 border rounded-xl">
    <h3>교실 대체 기기 조합</h3>
    <p>노트북/스마트폰 톤 생성 앱 + 스피커</p>
    <p>→ 스마트폰 앱 또는 노트북 마이크</p>
    <p>→ 파형 데이터</p>
    <p>→ 동일한 분석 흐름 적용</p>
  </div>
</div>

> 대체 장비에서는 절대 음압 비교보다 주기, 진동수, FFT 피크와 맥놀이 주기를 중심으로 해석한다.

# 연수 운영 원칙

- 활동은 측정도구 사용방법 소개(파형 확인) -> 모둠별 실습(간섭, 맥놀이) → 대체 실험도구 제시 순으로 진행
- 제공 자료: 실행용 Colab 노트북, 활동지, 결과 예시
  - 클래스룸에 활동지 기록 필요 -> 생활기록부 세특 예시
- 대체 실험 도구인 스마트폰 앱 및 웹 앱의 세부 조작은 MBL 실험 후 제공

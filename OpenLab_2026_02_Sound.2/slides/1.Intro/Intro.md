# 개방실험실 보유 자재 활용 과학탐구실험 자율연수

## MBL 기반 소리 측정과 파동 분석 수업

---

# 연수의 목적

- 실제 학생 수업에서 사용한 활동을 교사가 재현할 수 있는 수업안으로 정리
- 표준 장비인 MBL 소리 센서로 음압 데이터를 측정하고 분석
- 장비 여건에 따라 스마트폰, 노트북, 톤 생성 프로그램으로 대체하는 방법 소개
- 실제 Google Classroom 수업 사례와 학생 산출물은 추후 링크로 제공

---

# 연수의 표준 경로와 대체 경로

<div class="grid grid-cols-2 gap-8 mt-8 text-left">
  <div class="p-5 border rounded-xl">
    <h3>연수 표준 경로</h3>
    <p>함수발생기 + 스피커</p>
    <p>→ MBL 소리 센서</p>
    <p>→ 음압 데이터 CSV</p>
    <p>→ 컴퓨터 관찰 및 제공 코드 분석</p>
  </div>
  <div class="p-5 border rounded-xl">
    <h3>교실 대체 경로</h3>
    <p>노트북/스마트폰 톤 생성 앱 + 스피커</p>
    <p>→ 스마트폰 앱 또는 노트북 마이크</p>
    <p>→ 파형 데이터 CSV</p>
    <p>→ 동일한 분석 흐름 적용</p>
  </div>
</div>

> 대체 장비에서는 절대 음압 비교보다 주기, 진동수, FFT 피크와 맥놀이 주기를 중심으로 해석한다.

---

# 연수 운영 원칙

- 활동은 예측 → 측정 → 파형 관찰 → 물리적 해석 순으로 진행
- 측정 실패 시에도 배포 예제 CSV로 분석 활동을 계속할 수 있도록 준비
- 제공 자료: 예제 CSV, 실행용 Colab 노트북, 활동지, 결과 예시, 교사용 체크리스트
- 스마트폰 앱의 세부 조작은 별도 자료로 추후 제공
